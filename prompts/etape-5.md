# Étape 5 : fiches d'oral et scénario de démo

Modèle utilisé : Sonnet 5.5, sans mode Plan (documentation uniquement, aucun changement de code).

```
Crée un dossier docs/ avec 5 fichiers, en relisant le VRAI code (pas de mémoire) :

1. docs/oral-membre-1.md à docs/oral-membre-4.md : une fiche d'oral par membre, d'après la répartition de cadrage.md section 6. Chaque fiche contient :
   - "Ma partie en une phrase"
   - "Ce que je dis" : 5 à 8 phrases simples, à la première personne, comme un étudiant qui parle (2 minutes à l'oral max)
   - "Le code à montrer" : 2 ou 3 extraits courts (fichier + nom de fonction + numéros de lignes), avec ce qu'il faut dire sur chacun
   - "La démo à faire" : les clics précis à faire pendant l'oral pour prouver la protection
   - "Questions probables du prof" : 4 questions avec une réponse courte chacune
   - "En mes mots" : une section vide à compléter par le membre lui-même
2. docs/demo.md : le scénario de démo commun en 3 minutes, dans l'ordre, avec qui parle à chaque étape (Membre 1 à 4).

Ajoute docs/ dans la structure du README et de CLAUDE.md. Commit "Fiches d'oral et scénario de démo" puis pousse.
```
