# Prompts

Ce dossier conserve les **prompts** (consignes) que nous avons donnés à Claude Code à chaque étape du projet.

Ils montrent comment l'IA a été guidée : chaque prompt demande de relire [CLAUDE.md](../CLAUDE.md),
qui impose les règles de simplicité, de documentation et de sécurité du projet.

Un fichier par étape (par exemple `etape-1.md`, `etape-2.md`…).

Voir aussi la section « Comment nous avons utilisé l'IA » de [SECURITE.md](../SECURITE.md).
